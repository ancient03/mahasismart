# Rules Coding

### untuk memulai project

`php artisan serve`

### setelah memulai project

`npm run dev`

### untuk membuat database di phpmyadmin

`php artisan migrate`

### jika ada edit di database update menggunakan

`php artisan migrate:fresh`

`php artisan config:clear`

`php artisan make:component`
